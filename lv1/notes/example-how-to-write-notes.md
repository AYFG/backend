# 노트 작성 방법 — 예시

## ❌ 이렇게 쓰지 마세요 (정의 암기)

> JPA는 Java Persistence API의 약자로, ORM(Object Relational Mapping) 기술입니다.
> EntityManager를 통해 엔티티를 관리하며, @Entity 어노테이션으로 테이블과 매핑합니다.
> 영속성 컨텍스트는 1차 캐시 역할을 합니다...

## ✅ 이렇게 쓰세요 (경험과 Why 중심)

> **JPA를 왜 쓸까?**
>
> 원래는 JDBC로 SQL을 하나하나 직접 썼다.
> 그러다 JdbcTemplate을 써도 반복되는 SQL 문자열과 결과 매핑이 너무 귀찮았다.
> 결국 "객체를 그냥 저장하면 DB에 알아서 들어가게 할 순 없을까?" 라는 고민에서 JPA가 나왔다.
>
> **내가 느낀 체감 포인트:**
> - `em.persist(member)` 한 줄로 INSERT가 끝날 때의 전율
> - SQL 문자열 실수로 30분 날렸던 과거가 떠오르며 "이걸 왜 진작 안 썼을까" 싶어짐
>
> **알게 된 한계:**
> - N+1 문제를 직접 부딪혀 보고서야 "Lazy Loading이 항상 좋은 건 아니구나"를 체감
